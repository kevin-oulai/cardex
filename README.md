# CARDEX

A mobile-first collectible car card game.

## Deployment

This repository is configured for GitHub Pages using a GitHub Actions workflow.

Place the complete CARDEX V0.5 single-file game at the repository root as `index.html`, then push to `main`.

In **Settings → Pages**, choose **GitHub Actions** under **Build and deployment**. The site will appear at https://kevin-oulai.github.io/cardex/ once deployed.

## Current game features

Boosters, Garage, Daily Showdown and Profile. Current progress is saved locally in the browser. The global serial-number registry and multiplayer backend are not implemented yet.
